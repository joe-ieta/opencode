## 阅读规则

1. 先看顶层和分支概览，再使用该分支的操作手册；`oc:*`、`qtoc:*`、桌面发行命令不能跨分支运行。
2. Qt 归档文档保留当时的版本、验证结果和待办。当前状态以概览、维护方法和 PR 跟踪为准；归档中“目前”“唯一入口”等用语属于原记录。
3. 旧 V1 文档将 `/api/*` 称为实验面，是当时的历史描述；不要据此解释当前 V2 的公开协议。V2 以对应提交的 `packages/protocol` 和契约测试为准。
4. 已配置 CI、已打 tag、本地构建成功、Actions 成功、GitHub Release 可下载是不同状态，记录时分别核对。
5. 新增 fork 文档放入本目录；仅把功能性脚本、技能入口和 AGENTS 留在它们需要被发现的位置。向上游提 PR 时排除本目录与 `FORK.md`，除非该 PR 明确讨论文档本身。
