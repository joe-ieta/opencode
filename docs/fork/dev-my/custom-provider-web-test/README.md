# 自定义模型 v0.2 人工网页测试包

版本：`2.2.5-models-test.1`，Windows 10/11 x64 便携包，不需要安装 Bun、Node 或桌面应用。包含同一源码构建的 API 和网页资源，构建提交、渠道及校验值见 `build.json` 和 `SHA256SUMS`。

1. 解压整个 ZIP 到一个新的可写文件夹，不要覆盖已经安装的 OpenCode。
2. 双击 `Start-WebTest.cmd`。脚本启动专用 `models-web-test` 渠道，在默认浏览器打开一次性配对链接并自动登录。
3. 默认网页地址是 `http://127.0.0.1:4381`。如果被占用，可用 PowerShell 运行 `./Start-WebTest.ps1 -Port 4382`；不要关闭占用端口的其他程序。
4. 在网页打开一个测试文件夹，建议选包内 `.web-test-profile/home`。进入模型选择器 → **Custom providers**。
5. 测试完双击 `Stop-WebTest.cmd`。再次启动会保留本包的测试配置和数据。

启动脚本只操作包内 `.web-test-profile`，不会连接已安装版后台，不修改其配置、凭据、数据库、服务注册或更新源。测试关闭自动更新，默认不读取项目配置和个人 `.claude`，使用随包目录快照；浏览器仍可连接你显式填写的本地或远程模型服务。不要在这个测试服务中选择正式项目执行修改代码的任务。

请勿分享或上传 `.web-test-profile`：其中可能包含你在测试中保存的 API Key、服务密码和会话。更换解压目录会得到另一套测试数据；同机多个测试包需使用不同端口。

## 建议验收顺序

- 手动新增：填写 Provider ID、Base URL、可选 Key、模型 key 和请求模型 ID，保存；关闭后重新打开确认。仅保存不应自动改变原选模。
- 编辑与凭据：更改显示名、限额和工具/图片声明，保存并重开。检查凭据保存、失败重试、删除后的回退提示，不应回显已有 Key。
- 模型发现：通用 `/models`、Ollama native、LM Studio native。预览默认不勾选，只导入选中项，保留手填值。Ollama 勾选后再读取详情；未加载模型的理论上限不能填作当前 context。
- 高级字段：展开 Provider/Model advanced options，检查超时继承和 false、编码、兼容字段、推理选项、零价及分层价格、变体新增/删除；保存后再编辑一次，确认价格行身份没有偏移。headers/body 任意值仍通过源文件修改。
- 显式文本测试：先保存地址、Key 和请求模型 ID，再点击 **Test text response**；支持取消和重试。它会真的请求模型，可能加载模型或产生费用，只验证最多 32 个输出 token 的最小文本响应，不证明工具、图片或高级参数可用。
- 正常对话：只有需要验证实际推理时才显式选用模型并发送一个简短提示词。自动化验收使用隔离端点，真实 Ollama/LM Studio 和工具/图片推理仍需人工确认。

请记录浏览器、模型引擎和版本、Base URL 形状（隐藏凭据）、模型 ID、复现步骤及实际提示。不要把 API Key、配对链接或整个测试配置文件粘贴到 Issue。
