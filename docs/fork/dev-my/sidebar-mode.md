## 功能设计

| 范围                 | 行为与边界                                                                                                                                                                                                                                               |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 四种模式并存         | 保留 Top tabs、Side tabs（`vertical`）和 Inbox；新增 Side bar（`sidebar`）。初始默认值和已有选择不变，旧 `vertical` 不自动迁移。官方 `tab-strip.tsx` 没有进入本次贡献差异。                                                                              |
| Running sessions     | 独立且不可单独隐藏的运行区域，空状态也保留。跨当前可见服务器展示执行中的会话，包括未打开的主会话和子会话；显示工作/等待输入/等待批准状态、项目、目录分支与当前运行时长。区域独立滚动，上限为 `min(288px, 40dvh)`，常规高度约八行；切换分组不改变其范围。 |
| 历史与标签分离       | Recent sessions 和 Home 复用会话查询缓存及实时状态。展示历史不会把所有会话写进已打开标签集合；选择后才按现有导航打开。Recent 只列未归档的主会话，子会话仍可从父会话与 Running 进入。                                                                     |
| 分组与简单列表       | `By project` 和 `List` 共存。按现有 Project/worktree 归属分组，组键包含服务器和规范化路径；不把不同服务器的同名目录混为一组。每组初始展示五行，More/Show less 展开收起预览；选中的溢出会话保持可见。                                                     |
| 计数与上下文         | 区分最近列表数量、实际显示数量和项目历史总量；历史总量使用轻量 ID/归属清单。项目标题的 `+` 在该项目新建草稿；悬浮信息补充分支、工作树路径与上次结束时间。分支代表当前目录报告的分支，并非创建会话时的历史快照。                                          |
| 关闭、隐藏与重新打开 | 关闭已打开标签或隐藏历史行不删除会话；Home/搜索仍能找到并重新打开。删除继续使用明确的删除操作。项目隐藏是客户端本地偏好，重新打开同一路径时恢复相应历史项目 ID。                                                                                         |
| 排序与键盘           | 默认按最近活动排列并稳定处理相同时间；显式排序继续生效。分组内拖拽限制在原项目，不通过拖动更改项目归属。切换简单列表/分组保留排序，键盘按实际展示顺序导航。                                                                                              |
| Home 与官方模式      | 仅 Side bar 把 Home 项目清单扩展为服务器目录并尊重本地隐藏；其他模式继续展示本客户端已使用项目。扩展悬浮信息也仅由 Side bar 启用。                                                                                                                       |

后台 Project 仍使用官方现有的自动发现/登记模型；本功能不重新定义项目、不修改公开 API 或数据库。`C:\` 等附带登记项目的展示取舍仍可在独立模式中继续讨论。任意目录树、归档筛选、自定义标签/文件夹及 Inbox 的固定会话和项目过滤均不属于本次实现。

## 2026-11-01 本地维护优化

- 项目标题增加整组展开/收起按钮，提供 `aria-expanded` 与键盘激活；收起后不显示会话及 More 按钮，标题、计数和新建入口保留。收起状态保存于当前窗口 `sidebar.collapsedProjects`，键沿用服务器与规范化项目路径。恢复展开时保留原五条预览或 More 状态；List、运行概览及历史数据不受影响。新建项目草稿会先展开相应项目。
- 活动索引可能先于会话元数据到达。桌面运行时按需读取运行会话缺失的祖先元数据，使深层子智能体在重连后仍关联到顶层会话；不读取祖先 transcript，不将父会话伪造为后台 running。根会话的图标状态聚合自身及已知 family，Home 与 Side bar 共用该判断。
- 主会话和子智能体共用 Spinner。应用跟随系统且系统关闭客户端区域动画时，图标保留静态姿态，这是已有的减少动态效果设计；不是执行结束的依据。本机只读 Windows API 核对返回动画关闭。需要动画时可将应用内“减少动态效果”设为关闭，不改变系统设置。回归覆盖执行结束再启动、滚动离屏暂停与恢复、减少动态效果开启与关闭。
- 新增两个英文无障碍标签词条，按上游规范走英文回退；此前核对过的 31 个中文词条保留，非英语翻译另行评审。本轮不更新、新建 PR，不再发送测试邀请。
